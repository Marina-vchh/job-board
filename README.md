# Job Radar

Личный агрегатор вакансий: каждое утро собирает вакансии с сайтов и Telegram-каналов, убирает дубли,
оценивает каждую по профилям поиска (0–100) и показывает сводку и трекер откликов.

## Как открыть

**Проще всего:** скачайте файл [`job-radar.html`](job-radar.html) и откройте его в Chrome
(двойной щелчок). При первом входе приложение попросит придумать PIN-код.

> Не открывайте файл во встроенном предпросмотре (в почте, мессенджере, чате) — там закрыт интернет,
> и будет ошибка «Failed to fetch».

## Для разработки

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # dist/ — для хостинга (Netlify, Vercel, Supabase Storage)
npm run build:single   # dist-single/index.html — один файл
```

Настройки подключения — в `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`).
Там только публичный anon-ключ. Ключ `service_role` в код не добавлять никогда.

## Что есть в приложении

- **Сегодня** — новые вакансии за день, разбитые на «высокое совпадение» и «возможно подходит», кнопка «Искать сейчас».
- **Вакансии** — все вакансии с поиском, фильтрами (балл, статус, дата, профиль, источник), выгрузкой в CSV.
  В карточке: почему такой балл, контакты из текста, заметки, статус отклика, «Найти рекрутера на LinkedIn».
- **История** — каждый запуск поиска: сколько найдено, новых, дублей, ошибки источников.
- **Профили** — что ищем: должности, ключевые слова, исключения, страны, формат, зарплата.
- **Источники** — включить/выключить источник, импорт писем с подборками LinkedIn/Indeed/Glassdoor.
- **Настройки** — расписание, пороги баллов, уведомления, тема, смена PIN.
